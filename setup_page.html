Set up your machine to write Python

Follow along, top to bottom. Pick your system once below and every command switches to match it. Check off each step as you go — your progress is saved on this device.

Your system
1

Install VS Code

The editor we write our code in. Download page for every system: code.visualstudio.com/download. Or install straight from the terminal:

Windows · winget
winget install --id Microsoft.VisualStudioCode -e
macOS · Homebrew
brew install --cask visual-studio-code

No Homebrew yet? Install it from brew.sh.

Linux · Debian / Ubuntu
# add Microsoft's package repo, then install
sudo apt update && sudo apt install -y wget gpg
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > microsoft.gpg
sudo install -D -o root -g root -m 644 microsoft.gpg /usr/share/keyrings/microsoft.gpg
echo "deb [arch=amd64,arm64 signed-by=/usr/share/keyrings/microsoft.gpg] https://packages.microsoft.com/repos/code stable main" | sudo tee /etc/apt/sources.list.d/vscode.list
sudo apt update && sudo apt install -y code
✓
Check it worked

Close and reopen the terminal, then run code --version. You should see a version number.

2

Install uv

uv is one fast tool that manages Python itself, virtual environments, and packages. Install it first — it installs Python for us in the next step.

Windows · PowerShell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Run this in PowerShell even if you use cmd for everything else — it is a one-time install.

macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
✓
Check it worked

Open a new terminal, then run uv --version. If it says "not recognized" or "command not found", fully close every terminal and open a fresh one so it picks up the updated PATH.

3

Install Python

We let uv install and manage Python for us. The command is the same on every system:

all systems
uv python install 3.12
✓
Check it worked

Run uv python list — you should see 3.12 in the list.

4

Create & activate a virtual environment

A virtual environment keeps each project's packages separate. From inside your project folder, create one:

all systems · creates a .venv folder
uv venv

Now activate it. The command depends on your terminal:

Windows · Command Prompt
.venv\Scripts\activate.bat
Windows · PowerShell
.venv\Scripts\Activate.ps1
macOS / Linux
source .venv/bin/activate

When active, your prompt shows (.venv) at the start. To leave it later, run deactivate.

!
PowerShell blocks the activation script?

If Activate.ps1 errors with "…cannot be loaded because running scripts is disabled on this system", PowerShell is blocking the .ps1 script. Allow signed local scripts for your user — run once:

PowerShell · run once
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Answer Y if prompted, then run the activation command again. Prefer not to change it? Use Command Prompt instead — activate.bat is not affected by this setting.

5

Install Jupyter Notebook

With the environment activated ((.venv) showing in your prompt), install the notebook packages:

inside the active .venv
uv pip install jupyter ipykernel

jupyter is the notebook app; ipykernel lets this environment run as a notebook kernel. Now register it so notebooks can find your project's Python:

register the kernel
python -m ipykernel install --user --name=project-venv --display-name "Python (project-venv)"

Launch it:

opens in your browser
jupyter notebook
i
Prefer to stay in VS Code?

Open any .ipynb file directly in VS Code. Install the Python and Jupyter extensions (Extensions panel, Ctrl+Shift+X), then pick the Python (project-venv) kernel in the notebook's top-right corner.
