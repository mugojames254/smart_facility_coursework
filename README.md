# Smart Facility Management Coursework

Course materials for the Smart Facility Management practical sessions.

## Website

https://mugojames254.github.io/smart_facility_coursework

Students start at the course home page, which lists every class and links to its practical, slides and data.

## Contents

- `index.html` — course home: table of contents for all classes (edit the `CLASSES` list in its script to add a week)
- `setup.html` — Week 2 practical: workstation setup (VS Code, Git, uv, Python, Jupyter, PyTorch)
- `week04.html` — Week 4 practical: uv project workflow + exploring UGV scan data (point clouds)
- `week05.html` — Week 5 practical: meshes — surface reconstruction and measuring the corridor
- `setup_guide.md` — environment setup instructions (Git, PyTorch, etc.)
- `smart_facility_setup.pptx` — Week 2 slides: class program installation
- `point_cloud_lecture.pptx` — Week 4 lecture slides: what point cloud data is (15 slides, with speaker notes)
- `class_data.zip` — UGV scan dataset (trajectory CSV, lidar map, colored scan, BIM design) zipped as `data/`, used in Weeks 4 and 5; see `data/README.md` inside
- `assets/` — images used by the course pages
